# ONG Aumigos!

## Visão Geral

Este projeto é um sistema web desenvolvido para fornecer presença digital profissional e funcional para ONGs, incluindo páginas institucionais, cadastro e divulgação de projetos sociais, área para voluntários e doadores, e gerenciamento de informações da organização.
